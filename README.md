# OpenCV Image Classification using SVM

# Overview
This Projects demonstrates a simple image classification system using **OpenCV** for image preprocessing and a **Support Vector Machine(SVM)** FOR classification.

---

## Dataset
- **Dataset:** Scikit-learn Digits Dataset
- **Total Image:** 1797
- **Classes:** 10(Digits 0-9)

---

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

---

## Image Preprocessing
The following Preprocessing techniques were applied using Open CV:
- Converted images to uint8
- Resized images to 32×32 pixels
- Normalized pixel values

---

## Machine Learning Model
- Algorithms: Support Vector Mechine(SVM)
- Train/Test Split: 80% Training, 20% Testing

---

## Results
- Model Accuracy: **87.22%**
- Confusion Matrix generated
- Predicted vs Actual labels visualized
